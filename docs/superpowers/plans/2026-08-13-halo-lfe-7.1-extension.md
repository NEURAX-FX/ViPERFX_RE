# Halo LFE 7.1 Extension Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Restore Halo's exact reverse-engineered LFE synthesis so the Halo encoder produces seven directional channels plus a non-directional LFE sideband that stays aligned through Off, Simple, and KU100 render modes.

**Architecture:** Add a prepared `HaloLfeSynth` after Halo's continuous OLA/diffusion stage. Keep LFE outside ACN/SN3D and Scene Rotator; delay it only by the selected directional decoder latency, add it equally to L/R, then run the combined KU100 signal through headphone EQ and the existing post chain. Persist four new HIDL parameters and expose them as localized flat controls under `Halo 7.1`.

**Tech Stack:** C++17, C11 PFFFT, CMake 3.16.3, Android NDK 28.0.13004108, Kotlin, Jetpack Compose, MiuiX 0.9.x, JUnit, CTest, UBSan, ASan compile/link.

**Design Spec:** `docs/superpowers/specs/2026-08-13-halo-lfe-7.1-extension.md`

**Algorithm Authority:** `/root/HaloMixRE/docs/reverse-engineering/halo-upmix-dsp.md`, section `0x180067544` and exact `0x180050ed4` biquad generation.

## Global Constraints

- Read `/root/AndroidIDEProjects/ViPER4Android/Anget.md` before every App, build, or dependency task.
- LFE source channels are exactly Halo `L`, `R`, and `C`; surround and rear channels never feed it.
- Keep seven directional planes separate from the mono LFE plane in types and APIs.
- Never encode LFE into ACN/SN3D, rotate it, or assign it a KU100 direction.
- Generate LFE only after continuous OLA and Halo diffusion/rear processing.
- Use the exact Q=1 RBJ low-pass equations and the exact normalized frequency/gain mappings in the spec.
- Generate coefficients on the control/prepare side. `Process()` performs no trig, log, exp, allocation, lock, file I/O, logging, or random calls.

- Keep existing parameter IDs unchanged; use only `0x1207E..0x12081` for this extension.
- Do not change AIDL mmap format 6 or the HIDL-only/AIDL-hide policy.
- Do not add an automatic cinema +10 dB LFE boost.
- Do not feed Halo output into the current stereo Granular encoder.
- Do not edit MiuiX library source or remove Material Icons.

- [ ] **Step 5: Implement the per-sample loop**

```cpp
const float fL = filter_l_.Process(left[i]);
const float fR = filter_r_.Process(right[i]);
const float fC = filter_c_.Process(centre[i]);
const float active_split = split_ * enable_ramp_;
lfe[i] = (fL + fR + fC) * gain_linear_ * enable_ramp_;
left[i] -= fL * active_split;
right[i] -= fR * active_split;
centre[i] -= fC * active_split;
```

When disabled from a reset state, write zeros to `lfe` and do not alter the three source arrays. On an enabled-to-disabled transition, ramp both generated LFE and source subtraction to zero over one process block, then clear the three biquad histories. Pipeline delay storage drains the ramped tail naturally and is cleared only by pipeline reset/reprepare.
